# 학습 데이터 수집 기능

![학습셋 목록](docs/screenshots/dataset-list.png)

AI 모델을 고객사에 배포하는 사내 플랫폼에, 모델 재학습용 데이터를 **모으고 · 검사하고 · 검수해서 · 학습에 넘기는**
기능을 새로 붙였습니다. 공격 페이로드, 악성 파일, 네트워크 패킷, 로그 같은 보안 데이터를 다루기 때문에
올라온 파일을 그대로 믿지 않고 자동 검사와 사람 검수를 거치게 만드는 것이 핵심이었습니다.

> 사내 프로젝트라 소스 코드는 공개하지 않습니다. 화면 사진은 시험용 데이터로 찍었고, 회사·제품 이름은 가렸습니다.

## 한눈에

| | |

| 규모 | master 병합 177개 파일 (문서 포함) |

| 제약 | 기존 코드는 고치지 않고 추가만. 기존 파일 변경은 명세가 지시한 8곳으로 한정 |

## 흐름

![수집 흐름](docs/screenshots/flow.png)

고객이 제출한 데이터는 자동 검사를 거쳐 검수자에게 가고, 승인된 것만 묶여 학습으로 넘어갑니다.
모델이 틀리면 오탐 신고가 다시 제출로 이어집니다.

## 화면

### 파일 업로드

파일 선택 → 업로드 → 분류 → 동의·제출, 4단계로 올립니다. 여러 파일과 폴더를 한 번에 고를 수 있고,
압축 파일은 풀어서 항목별로 등록합니다. 큰 파일은 조각으로 나눠 올려서, 끊겨도 처음부터 다시 올리지 않습니다.

![파일 업로드](docs/screenshots/upload-wizard.png)

### 검수

검수자는 본문 미리보기와 SHA-256, 이미 들어온 비슷한 데이터("거의 같음")를 보고 승인하거나 반려합니다.
라벨은 추천값을 눌러 붙일 수 있고, 반려할 때는 사유가 필수이며 그 사유가 제출자에게 그대로 전달됩니다.

![검수](docs/screenshots/review.png)

### 격리함

자동 검사에서 악성으로 판정된 파일은 격리함으로 갑니다. 실체는 암호화된 상태로만 보관하고,
꺼낼 때는 사유를 남겨야 하며 비밀번호가 걸린 압축 파일로만 내려받습니다.

![격리함](docs/screenshots/quarantine.png)

### 릴리스

승인된 학습셋을 한 시점에 고정한 스냅샷입니다. 만들면 바로 동결되어 구성이 바뀌지 않고,
학습 쪽에 넘길 목록 파일(매니페스트)이 함께 만들어집니다.

![릴리스](docs/screenshots/release.png)

### 권한

권한은 비트 정수 하나로 저장하고, 자주 쓰는 조합은 프리셋으로 제공합니다.
검수는 권한만으로는 안 되고 해당 컬렉션에 배정돼 있어야 합니다.

![권한](docs/screenshots/permissions.png)

## 만들면서 한 판단

**대조는 "있는가", 실제로 띄워 보기는 "맞게 도는가".** 자동 리뷰 코멘트 550건을 하나씩 판정하고 명세 대조를
두 번 통과한 뒤에도, 로컬에 운영 빌드를 띄워 파일을 직접 올려 보니 결함이 곧바로 나왔습니다.
개인정보 마스킹이 개인정보만이 아니라 **공격 페이로드 원본까지 지우고 있어서**, 그대로 두었다면 학습용
데이터가 훼손된 채 넘어갈 뻔했습니다.

**자동 리뷰는 추측과 결함을 가려서.** 리뷰 봇 코멘트 550건 대부분은 코드를 보지 않고 변경분만 보고 한
추측이었습니다. 실제 결함만 골라 고쳤습니다 — 직접 입력 본문의 마스킹 누락, 마지막 관리자가 잠기는 경합,
업로드 재개가 실제로는 처음부터 다시 올리던 문제.

**VirusTotal을 쓰던 곳이 약관 위반이었다.** 해시 조회에 쓰던 무료 API는 상업적 이용이 금지돼 있었습니다.
대체 후보 12개를 조사해 "회사에서 쓸 수 있는가"를 필수 조건으로 걸었고, 그 결과 실측이 가장 좋았던 두 곳이
빠졌습니다. 남은 **ClamAV + YARA · NSRL · CIRCL**로 역할을 나눠 채웠고, 검사할 파일 자체는 밖으로 보내지
않습니다(나가는 것은 64글자 지문뿐).

**"로드됐다"와 "작동한다"는 다르다.** ClamAV 로그에 YARA 규칙 4,665개가 로드됐다고 나와 그대로 보고했는데,
규칙마다 반응하는지 세어 보니 실제로 작동하는 것은 **9개(0.2%)** 였습니다. ClamAV는 읽지 못하는 규칙이
하나 있으면 그 뒤 규칙을 로드 성공으로 표시하고도 발동시키지 않았습니다. 파일 단위였던 선별을 규칙 단위로
바꿔 **93.9%(4,500/4,794)** 를 살렸고, 정상 파일 26,768개(10.23GiB)에서 오탐은 0건이었습니다.

## 지금 상태와 한계

- 수집 기능 전체는 master에 병합됐고, 운영 서버 배포는 배포 절차를 확인한 뒤 진행할 예정입니다.
- VirusTotal 대체분(ClamAV + YARA · NSRL · CIRCL)은 구현과 리뷰를 마치고 병합을 기다리고 있습니다(2026-09-23 기준).
- 악성 파일 **탐지율은 측정하지 않았습니다.** 사내에 악성 검체를 안전하게 보관할 환경이 없어 업무 PC에 검체를
  두지 않기로 했고, 운영 로그로 집계할 계획입니다.
