# CCTV 라벨링 도구

`Python` `Tkinter` `OpenCV` `YOLO12` · 2026.07–08 · 1인 개발

![라벨링 도구 화면](docs/annotator.png)

<sub>실제 도구 화면입니다. 사람이 드러나지 않도록 영상 장면은 전체를 흐리게 했고, 박스와 라벨은 화면 구성을 보여 주기 위한 예시입니다.</sub>

CCTV 영상을 넣으면 프레임 이미지와 박스 라벨을 만들고, YOLO로 바로 학습할 수 있는 데이터셋(train/val 분리, `data.yaml`, zip)으로 내보내는 데스크톱 도구입니다.
걷기·서기 판정 모델을 만들다가 필요해서 만들었고, 걷기·서기 판정과 화분·야구방망이 탐지의 학습·검수 데이터를 이 도구로 만들었습니다.

- 자동 라벨링(영상 → 프레임 → YOLO 자동 라벨 → 데이터셋)과 수동 라벨링·검수를 한 도구에서 처리
- Windows 실행 파일(.exe)로도 묶어서 파이썬 없이 실행
- 기획과 구현을 혼자 했고, 실제 라벨링 작업에도 직접 썼습니다

사내 작업에 쓰려고 만든 도구라 소스 코드는 비공개 저장소에 있습니다.

## 만든 이유

상용 라벨링 도구는 CCTV 작업 흐름과 맞지 않아서, 아래 일들을 전부 손으로 해야 했습니다.

| 손으로 하던 일 | 도구에서 |
|---|---|
| 영상에서 프레임을 뽑아 따로 불러오기 | 영상을 열면 바로 프레임 추출 (전 프레임, N프레임 간격, 초당 N장) |
| 가만히 서 있는 사람을 수십 프레임 동안 반복해서 그리기 | 선택한 박스를 다음 N프레임에 복사 |
| 여러 프레임에 걸쳐 같은 자리에 생긴 오탐 박스 지우기 | 같은 위치의 박스를 범위 안에서 한 번에 삭제하거나 클래스 변경 |
| 1차 라벨이 맞는지 한 장씩 눈으로 확인 | 검수 모드 (아래) |

## 기능

- YOLO로 박스를 미리 깔아 두고 사람은 고치기만 합니다. 이미 박스가 있는 자리는 건너뜁니다.
- 박스는 드래그로 그리고 옮기고 크기를 바꿉니다. 휠로 커서 기준 확대, 우클릭으로 화면 이동, 되돌리기가 됩니다.
- 대부분 키보드로 합니다. `A`/`D` 앞뒤, `PageUp`/`PageDown` 10장씩, `U` 다음 미라벨 프레임, `1`~`9` 클래스 선택입니다. 한글 입력 상태에서도 단축키가 먹게 했습니다.
- 바꾼 내용은 바로 저장돼서, 도구를 닫았다가 같은 폴더를 열면 이어서 작업할 수 있습니다.
- 내보낼 때 거의 같은 프레임은 덜어 냅니다. 몸 높이에 비해 얼마나 움직였는지와 이미지 해시(dHash)로 비슷한 프레임을 찾습니다.
- 이미지와 라벨은 항상 1:1로 맞춥니다(객체가 없는 프레임은 빈 라벨). train/val 분할과 `data.yaml`도 자동으로 만듭니다.

## 검수 모드

1차 라벨(자동 탐지 결과나 이전 작업분)을 키보드만으로 빠르게 확인하는 모드입니다. 켜면 오른쪽 패널이 접혀서 이미지가 화면 대부분을 차지하고, 판정할 박스만 강조되고 나머지는 흐려집니다. 재생하거나 슬라이더로 구간을 넘기면서 판정하면 결과가 그대로 라벨에 반영됩니다.

직접 라벨링을 해 보니 라벨을 만드는 것보다 만들어진 라벨이 맞는지 확인하는 데 시간이 더 들어서 이 모드를 추가했습니다.
